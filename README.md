# IPL-2024-Data-Analysis
IPL 2024 Player Statistics Analysis using Python, Pandas and Matplotlib

## Overview
This project analyzes IPL 2024 player statistics to find insights about 
top batsmen, bowlers, and all-rounders using Python and Pandas.

## Libraries Used
- Python
- Pandas
- Matplotlib

## Key Analysis
- Top 10 Batsmen by Runs Scored
- Top 10 Bowlers by Wickets Taken
- Top 10 Six Hitters
- Top 10 Players by Batting Average
- Top 10 Players by Strike Rate
- Batting Average vs Runs Scored
- Economy Rate vs Wickets Taken
- Top 5 Batsmen Runs Share (Pie Chart)

## Key Findings
- Players with high batting average tend to score more runs
- Bowlers with low economy rate take more wickets
